Sistem Photobox Kiosk

This project is an integrated Photobox application developed using Laravel 12 as the backend system and admin panel, and Electron JS as the desktop kiosk application that handles the photo-taking process and customer transaction flow. This system supports machine management, payment flows via QRIS and vouchers, and cloud-based photo storage.

1. Frontend Flow (Desktop Kiosk)

The Desktop Application uses Electron JS to provide a kiosk interface that customers can access directly, from selecting a payment method, through the photo shoot, applying effects, to printing and downloading photos.

1. Setup / Integration

connecting desktop applications with the backend system.

2. Welcome Screen (Boarding)

The initial standby screen invites customers to begin their photo booth session.

3. Payment Method

Selection between automatic QRIS mode or using a voucher.

4. QRIS Payment

QRIS barcode display generated directly from the system.

5. Voucher Payment

Payment alternatives include voucher codes created by the admin.

6. Extra Print

Users are offered additional print options before selecting a frame.

7. Select Frame

Users can choose from a selection of photo layouts already stored on the server.

8. Photo Session

The moment of live shooting by the kiosk camera.

9. Preview

Review the photos that have passed the selection process, including frames and filters.

10. Effects & Filters

Select a filter color before the rendering process is complete.

11. Results Page

Equipped with QR Code to download softcopy of photo.

Staff Only Area (Frontend)

Input Authentication PIN

Special entry protection for kiosk machine officers.

Switch Mode App (Shortcut)

shortcut to enter developer mode, admin mode and view gallery.

Application Settings

Synchronize data (engines, assets, frames) with Laravel server.

Gallery Page

Displays a gallery of the results of the photo session that was carried out.

2. Backend Flow (Laravel Admin Panel)

A back-office system that acts as the central control center for all applications. From per-machine transaction analytics to PNG frame management, everything is handled centrally.

Dashboard

A concise information center and overall system status.

Analytical Report

Printed transaction reports come in from daily to monthly.

Machine Management

Setup of individual Photobox machines from various locations.

Frame List

A catalog of frame displays (photo overlays) available on the Front end.

Adding a New Frame

Upload and plot a photo grid on a transparent PNG image.

Frame Editor

Edit the photo grid layout using the integrated editor in the Admin Panel.

Manage Pricing

Printing and extra printing rate settings.

Voucher Management

View a list of discount vouchers or free vouchers created.

Add Master Voucher

*Generates* a random code for voucher use by the Customer.

Transaction History

A table showing all incoming transactions and their success/pending status.

Master Gallery

View photos captured by various machines across the local network.

Admin Profile Settings

Customize the admin manager information and *password*.
